# Japanese Restaurant Menu App 🍣

A Flutter mobile application created for **LAB 3 (TMA3084)**. The app displays a single-screen Japanese cuisine menu using custom `Card` widgets and includes interactive navigation to a detailed food view screen.

## 🌟 App Features

* **Japanese Cuisine Theme:** Features three classic Japanese dishes:
  * **Takoyaki** (*たこ焼き*) – Street Food / Appetizer
  * **Tonkotsu Ramen** (*豚骨ラーメン*) – Main Course
  * **Matcha Parfait** (*抹茶パフェ*) – Dessert & Beverage
* **Blue & Brown Color Palette:** Designed with a deep indigo navy primary color (`#1B263B`), warm earth brown accents (`#8D5B4C`), and a soft off-white background (`#F7F4EF`).
* **Interactive Navigation:** Tapping any item card smoothly navigates to a detailed screen displaying the dish's category, pricing, description, and Japanese name.
