# Japanese Restaurant Menu App (`restaurant_menu`)

A simple Flutter lab assignment featuring a single-screen restaurant menu built using `Card` widgets, styled with a traditional Japanese aesthetic, and equipped with a detail-view navigation feature.

## 👩‍💻 Student Information
* **Name:** Aina Alisya
* **Matrix No:** 102397
* **Course / Lab:** TMA3084

---

## 🌟 Features
* **Japanese Cuisine Theme:** Displays three featured dishes (Takoyaki, Tonkotsu Ramen, and Matcha Parfait) with English and Japanese subtitles.
* **Card Layout:** Built using custom Flutter `Card` and `InkWell` widgets.
* **Blue & Brown Palette:** Styled with a custom deep indigo blue (`#1B263B`) and warm earth brown (`#8D5B4C`) color scheme.
* **Optional Navigation:** Tapping any food card smoothly navigates to a detailed information screen showing descriptions and pricing.
